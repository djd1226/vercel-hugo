前言#

出于 Claude Code 的限制加上本人并不想花太多时间在环境上折腾，之前使用 Claude Code CLI 分别配合过 GLM 4.5、Kimi K2、DeepSeek 3.1、Qwen3 Coder 以及一些中转站，整体来说能用，但总感觉差点什么。

直到腾讯发布了 CodeBuddy Code CLI，号称可平替 Claude Code 且国内可无网络限制使用，便第一时间进行了体验。

优劣势分析#

核心优势#

  • 限时公测免费：无需邀请码。
  • 多模型切换：可调用 Gemini Pro 2.5 和 Claude Sonnet 4 模型（国际版）。

当前限制#

  • 暂不支持 /agents、/hooks、/ide 等高阶能力。
  • 暂不支持后台任务。
  • 暂不支持 HTTP/SSE 协议的部分 MCP。
  • 版本分流：
    • 国内版：仅支持 DeepSeek 3.1 等少数模型。
    • 国际版：支持 Claude Sonnet 4 和 Gemini-Pro 2.5，但消耗的是 CodeBuddy IDE 国际版权益（新用户 2 周一次性 500 积分，老用户每日 50 积分免费额度）。

简介与安装#

CodeBuddy Code CLI 是面向专业工程师的 AI 命令行工具，支持通过自然语言驱动全流程开发。它具备智能代码库分析、内置完整工具链、多场景任务自动化等特性，与插件和 IDE 构成完整的 AI 编程生态。

前置条件#

  • Node.js：18 及以上版本

一键安装#

# 全局安装 CLI
npm install -g @tencent-ai/codebuddy-code

# 验证安装
codebuddy --version

登录授权与模型支持#

在命令行输入 codebuddy 即可启动，首次使用需对当前工作目录进行访问授权。支持两种登录方式：

1. Google / GitHub 登录（走国际版体系）#

  • 默认按回车选择此项。
  • 浏览器弹出 CodeBuddy IDE 国际版授权页面。
  • 若选择 Google 登录，需完成 Gmail 验证邮件点击确认。
  • 可用模型列表（输入 /model 查看）：
    • Claude 系列：Claude-4.0-Sonnet
    • Gemini 2.5 系列：Gemini-2.5-Flash、Gemini-2.5-Pro
    • GPT 系列：GPT-5、GPT-5-mini、GPT-5-nano、GPT-4o-mini

2. WeChat 微信登录（走国内版体系）#

  • 终端选择 Login with WeChat，浏览器调起微信扫码授权。
  • 可用模型列表：
    • Default（默认模型）
    • DeepSeek-V3.1
    • DeepSeek-V3

CLI 参数与常用命令#

在终端执行 codebuddy --help 可查看全部参数说明：

子命令#

命令说明
config管理全局/项目配置
mcp配置与管理 MCP 服务器
doctor检查代码更新器与环境健康状况
update检查并在有新版本时自动升级
install安装 CodeBuddy 原生稳定版/指定版本
migrate-installer从全局 npm 安装迁移到本地安装

启动选项#

# 快速开启一次对话
codebuddy "优化当前目录下的 package.json 依赖"

# 恢复/继续会话
codebuddy -c            # 继续上一次会话
codebuddy -r            # 恢复指定会话 (resume)

# 查看 MCP 列表
codebuddy mcp list

# 开启免确认自动运行模式 (类似 Cursor 的 auto-run)
codebuddy --dangerously-skip-permissions

常用可选参数表：

  • --continue：继续最近的对话
  • --resume：恢复对话（提供会话 ID 或交互式选择）
  • --model：指定本次会话调用的模型
  • --dangerously-skip-permissions：绕过所有权限检查（仅建议在隔离沙箱中使用）
  • --permission-mode：权限模式 (acceptEdits / bypassPermissions / plan)
  • --allowedTools / --disallowedTools：工具白名单/黑名单过滤
  • --add-dir：挂载额外允许工具访问的目录

交互模式与快捷键#

在 CLI 会话内输入 /help 可唤起交互命令列表：

指令作用指令作用
/add-dir挂载新的工作目录/workspace切换工作空间目录
/clear清除历史记录并释放上下文/compact压缩对话历史保留摘要

常用快捷键#

  • Ctrl + C：取消当前生成（连按两次退出）
  • Ctrl + D：退出会话
  • Ctrl + L：清屏
  • Shift + Tab：循环切换对话模式（手动 / 自动接收编辑 / 绕过权限）
  • Tab：自动补全指令
  • Ctrl + J：输入框多行换行
  • ↑ / ↓：回溯历史输入
  • Esc + Esc：切换历史消息

配置文件结构#

配置文件采用分层覆盖机制，优先级规则：
$$\text{Local (本地)} > \text{Project (项目)} > \text{User (全局)}$$

1. settings.json#

  • 全局配置：~/.codebuddy/settings.json（跨项目生效，不进 Git）
  • 项目配置：[项目根目录]/.codebuddy/settings.json（团队共享，建议入 Git）
  • 本地配置：[项目根目录]/.codebuddy/settings.local.json（当前会话覆盖，需加入 .gitignore）

2. 记忆文件 (CODEBUDDY.md)#

运行 /init 可自动生成，用于持久化上下文偏好：

  • 全局偏好：~/.codebuddy/CODEBUDDY.md（个人编码习惯与风格）
  • 项目约定：[项目根目录]/CODEBUDDY.md（架构设计、项目约束规则）

3. MCP 扩展配置#

  • 全局生效：写入 ~/.codebuddy.json 下的 mcpServers 字段。
  • 项目生效：写入 [项目根目录]/.mcp.json 文件。

4. 自定义命令目录 (commands)#

将 .md 文件放入指定目录即可注册为 /<文件名> 快捷命令：

  • 全局目录：~/.codebuddy/commands/
  • 项目目录：[项目根目录]/.codebuddy/commands/

核心功能体验#

Shell 指令执行#

在命令行前输入 ! 即可进入 Bash 模式直接执行系统命令（如 !ls、!git status），无需离开 CLI 或新开窗口。按 ESC 退出该模式。

Chat 与上下文管理#

  • 文件引用：输入 @ 会自动列出工作区文件，选中即可将代码文件挂入聊天上下文（暂不支持多级子目录文件快速索引）。
  • 图片多模态：支持通过快捷键 Ctrl/Cmd + V 直接将剪切板中的截图粘贴到终端。

对话模式切换#

  1. 手动模式 (Default)：对每次文件修改或 Shell 执行均会进行权限弹窗二次确认。
  2. 自动接受编辑模式 (accept edits)：无需频繁确认，CLI 自动创建和修改代码文件，但受到只读文件等安全机制限制。
  3. 绕过权限模式 (bypass permissions)：直接静默执行所有文件与指令变更。

自定义斜杠命令#

在 .codebuddy/commands/ 下新建 greet.md：

请问候用户 $1，并以严谨的代码架构师语气给出项目建议。

在终端输入 /greet Alice 即可自动执行预设 Prompt 任务（也兼容 $ARGUMENTS 语法获取全部传参）。

记忆文件 (CODEBUDDY.md)#

支持通过交互指令 # 快速将特定规范追加写入到记忆文件中，如：

# 强制所有函数必须补充 JSDoc 注释

(注：实测当前版本项目级记忆文件生效稳定，全局记忆文件仍有待优化)

MCP 服务配置#

方式一：CLI 命令行配置 (推荐)#

# 添加标准 stdio 类型的 MCP
codebuddy mcp add context7 -- npx -y @upstash/context7-mcp

# 添加 HTTP/SSE 协议 MCP
codebuddy mcp add --transport http context7 https://mcp.context7.com/mcp

# 查看当前已装载的 MCP
codebuddy mcp list

方式二：.mcp.json 项目配置#

在项目根目录下创建 .mcp.json：

{
  "mcpServers": {
    "context7": {
      "args": [],
      "url": "https://mcp.context7.com/mcp",
      "type": "http"
    }
  }
}

总结#

CodeBuddy Code CLI 的设计思路与 Claude Code 类似，主打无终端缝隙的 AI 交互编程。目前其基础的命令行体验、多模型接入、快捷指令以及简单的 MCP 联动已经打通，国内网络可用度较好。

不过，核心的 /agents（多智能体协作）、/hooks（工具触发钩子）以及深度 /ide 集成等特性目前尚未补齐。如果是追求免折腾网络、需要快速在终端使用多模型审查或生成代码的开发者，可以尝试体验。
