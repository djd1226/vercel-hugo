Google 精准分流（WARP）总结文档

适用于被 Google “送中”的 VPS，需要正常使用 Google 服务（尤其是 Antigravity CLI agy），同时不影响其他业务（如 x-ui 代理节点）。

1. 原理说明#

Cloudflare WARP 把流量通过 Cloudflare 网络出口。
精准分流只把命中 Google 官方 IP 段（CIDR）的流量（IPv4/IPv6、TCP/UDP/QUIC）路由到 WARP，其他所有流量继续使用 VPS 原生 IP。

结果：

  • Google 看到的是 Cloudflare 干净 IP，解除“送中”。
  • x-ui 面板、节点出站、其他业务完全不受影响。
  • 资源占用极低（内存通常几十 MB，CPU 几乎可忽略）。

2. 适用环境#

  • 系统：Ubuntu
  • 虚拟化：KVM（支持 TUN，完美兼容）
  • 已安装：x-ui / 3x-ui（不冲突，脚本明确不改代理配置）
  • 目标：正常使用 agy、Gemini、YouTube、Gmail 等 Google 服务

3. 推荐安装方式（已验证成功）#

使用专门的 warp-vps-manager 脚本（Google 精准分流 + WireGuard 模式）：

# 以 root 执行
bash <(curl -fsSL https://raw.githubusercontent.com/mqfut123/warp-vps-manager/main/install.sh)

安装过程选择：

  1. Google 精准分流（默认推荐）
  2. 建议添加 1G Swap（可选）
  3. 模式选择 WireGuard（支持完整协议，包括 QUIC）

安装完成后会提示：

  • 安装模式：WireGuard 模式
  • 路由范围：精准分流 Google 服务
  • 并给出当前 WARP 公网 IPv4
  • 管理命令：warp-vps

4. 安装后验证#

# 确认 WARP 已开启
curl https://www.cloudflare.com/cdn-cgi/trace | grep warp
# 应显示 warp=on

# 查看状态
warp-vps status

# 解锁检测
warp-vps test

你当前已通过的检测结果示例：

  • Gemini：可用
  • YouTube Premium：可用（页面地区：US）
  • WARP 出口 IP：104.28.165.128（Cloudflare）

5. 安装并测试 Antigravity CLI（agy）#

curl -fsSL https://antigravity.google/cli/install.sh | bash
agy

第一次运行会触发 Google 登录。因为流量已精准分流到 WARP，认证和模型调用通常可正常完成。

6. 日常管理命令#

warp-vps              # 打开交互菜单
warp-vps status       # 查看运行状态
warp-vps test         # 解锁检测
warp-vps restart      # 重启服务
warp-vps logs         # 查看日志
warp-vps change-ip    # 更换 WARP IP（如遇限速）
warp-vps uninstall    # 卸载

7. 与 x-ui 的兼容性#

  • 系统级出站分流，不修改 x-ui / Xray 的任何配置。
  • 用户连接你的节点时，流量仍按原有规则走。
  • 只有 VPS 本机主动发起的 Google 流量（agy、curl Google 等）走 WARP。

8. 资源与速度影响#

  • 内存：通常 30–50 MB
  • CPU：几乎可忽略
  • 网速：仅 Google 相关流量有极小延迟增加（洛杉矶到 Cloudflare 通常很近），其他业务零影响

9. 常见问题与处理#

  • 安装时提示找不到 wireguard-tools：先执行
    apt update && apt install -y wireguard-tools
    然后重新运行安装脚本。
  • 如果 agy 仍有问题：把完整报错贴出，检查是否涉及特殊域名或 IPv6。
  • 想换 IP：使用 warp-vps change-ip。
  • 想卸载：warp-vps uninstall。

10. 备选方案（如主脚本不可用）#

官方客户端 + 透明代理脚本：

bash <(curl -fsSL https://vpszdm.com/warp-google.sh)

选择「安装 WARP 解锁 Google」即可。

当前状态总结（你的机器）
已成功安装 WireGuard 模式 Google 精准分流，Gemini / YouTube Premium 解锁通过，可直接使用 agy。
